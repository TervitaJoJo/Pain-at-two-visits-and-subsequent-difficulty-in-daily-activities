Do not use post-wave-8 updated vital status as if measured at wave 8.

No imputation of pain, ADL, death or proxy. Preserve original primary imputation for primary-derived analyses.
3. SHARE: censor before any proxy participation (PH054=2 or 3) at follow-up; additional strict rule also censors unknown respondent status. Estimated-weight variance treated as fixed for this sensitivity and explicitly disclosed.
4. History contribution: D1 MI joint Wald test H0 beta10=0 and beta11-beta01=0 using participant-cluster covariance; 11 versus 01 contrast. No prediction performance claim.
5. Model-standardized four-year NET ADL risks under two nominal 2-year intervals, standardized to each eligible cohort population. Delta-method covariance conditional on the empirical standardization population, Rubin pooling on logit scale for risks and raw scale for risk differences. Use primary fits, and first-visit-function adjustment as sensitivity. These are model-based net probabilities under independent outcome censoring, NOT death-adjusted real-world cumulative incidence, causal risks or treatment benefits. Audit follow-up support. If death data permit, separately report observed-wave competing outcomes and/or ADL-or-death composite; avoid invented exact ADL event dates. Report reasons for unavailable competing-risk modeling.
6. SHARE death-sensitive composite: known death by the corresponding follow-up wave or observed ADL, nominal 2-year intervals, same core adjustment and original MI. Compare with ADL-only nominal intervals. Death and ADL definition differences prevent automatic pooling with primary ADL estimates. Do not infer ADL onset before death for unobserved interviews.

Include all specified results. SHARE leave-one-country-out sensitivity with all 50 imputations.
