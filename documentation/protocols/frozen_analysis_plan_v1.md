# 关联分析前方案 v1

制定时间：2026-10-29；在查看暴露—结局关联估计之前制定。已经查看文献和无关联的聚合容量。此为本地分析方案，未声称已在公共平台注册。

## 问题与对象

研究中老年糖尿病人群中两次频繁疼痛报告的变化，与后续新报告基本日常活动困难的关联。糖尿病由harmonized医生诊断糖尿病/高血糖指示r{w}diabe界定，不称为经过实验室确认或已区分分型的糖尿病。年龄≥50岁，两次暴露访视均本人回答且均无五项ADL困难。

HRS为主分析队列，ELSA为独立参与者队列的关联复核；不把复核叫作预测模型外部验证。两库的入组与波次选择见capacity_plan.json，逐人最早合格窗口不取决于未来是否失访。基线名义年份2010或2012；两年后界定疼痛变化；其后的两次访视用于观察约四年内结局。

## 暴露与结局

暴露00、01、10、11依次为两次均无、第二次新报告、第二次不再报告、两次均报告频繁疼痛。主要对比11 vs 00；次要01 vs 00、10 vs 00、10 vs 11。四组使用同一模型估计，不为取得显著性重设阈值。主要假设是11组有更高的后续ADL困难报告率；对10组是否接近00组不作保证。

结局为穿衣、洗澡、进食、床上转移、如厕任一项新报告困难。任一项为1则结局为1；判定0要求五项均为0；其余为缺失。主分析遇首次结局缺失即停止后续观察；首次报告事件后停止。后续恢复不改变曾首次报告事件的事实。仅两年间隔测量，不能识别访视间发生又缓解的短暂困难，也没有精确发病日。

## 主模型

采用按访视区间整理的离散时间回归，使用互补对数对数链接，区间长度以实际访视月份差计算并加入log(年数)偏置项；区间指示允许两个随访阶段有不同基线率。使用按参与者聚类的稳健标准误。系数指数化称为离散时间比例风险框架下的关联估计，解释依赖区间内风险近似恒定等假设，不能声称观测到了确切发生时间。实施时应检验模型收敛、极端权重、稀疏单元和系数不稳定；若不得不更改主模型，须在查看ELSA关联前记录理由与版本，不根据显著性选择模型。

主调整集（暴露起始访视）：年龄（连续）、性别、三档教育、当前吸烟、关节炎、心血管病史（心脏病或卒中）、CES-D8（连续，要求八项完整计算）；另含入组窗口与随访区间。HRS教育raeduc映射为1=未完成高中，2/3/4=GED/高中/部分大学，5=大学及以上；ELSA raeducl使用低于高中、高中/职业、三级教育三档。两国教育制度仍有差异，映射是近似对应。所有二元协变量只把有效0/1作为已知；CVD任一病种明确1记1、两者都0记0、否则缺失。

现有容量HRS 510个、ELSA 99个首次缺访前事件，支持较克制的调整集；不是正式功效计算，不能保证小组对比的精度。HRS不使用更复杂模型去筛出一套只有本库显著的设置后再称为固定外部复核。

协变量缺失：主分析使用50次多重插补，在每个队列内单独执行，插补模型包括固定协变量、暴露组、入组窗口、可观测事件与随访信息；适当使用逻辑/多项模型及预测均值匹配。按Rubin规则合并系数及方差，固定随机种子。完整病例作为敏感性分析。疼痛、入组ADL和主随访结局不由该插补步骤填造。

## 预设补充与敏感性分析

- 报告各组数量及随访缺失；关联建模开始后才生成暴露组的事件数/事件率。展示所有预设对比及区间，不只挑显著结果。
- 两个队列分别估计，首先看方向和估计精度；两个队列不宜据异质性检验未显著就宣称完全相同。汇总效应如报告仅为补充，不用合并显著性替代外部队列结果。
- 完整病例敏感性；加入更严格功能与疼痛严重度控制的敏感性仅在对应变量核验后实施。若分析10 vs 11，须特别注意两组基线严重度不同和回归均值，不能解释为治愈/治疗效果。
- 失访敏感性：在具有所需基线变量且满足可识别假设时，以预先固定的观察概率模型构造稳定权重，并在1%和99%分位截尾；报告权重分布与有效样本量。它不能解决未观测原因导致的死亡或失访偏倚，ELSA尤其如此。
- HRS另做死亡/功能困难相关的敏感性分析，实施前核验死亡时间及可用样本；ELSA缺乏完整后期死亡识别，不承诺复制同一竞争风险或死亡复合结局。
- 横断面为单独的补充样本：每位受访者取2010/2012中最早符合年龄、糖尿病、疼痛与ADL有效的起始访视，不按之后随访完整与否筛选，也不要求ADL为0；使用稳健Poisson估计患病率比，调整同一基线协变量。结果标注为补充关联，不提供独立纵向验证。

不安排无明确假设的中介分析、机器学习、四库拼接、几十个亚组或大量替换结局。本方案关注本次选择的问题；其他问题应有单独记录，不能隐藏本项目的阴性估计。

## 局限与报告约束

研究对象是存活至两次暴露测量且保持基本ADL独立者，存在生存和健康选择。自报糖尿病/高血糖不能区分病型；一般性疼痛不能视为糖尿病神经病理性疼痛。两次报告不能证明连续疼痛或临床缓解。ADL结局和疼痛均自报，残余混杂与共同方法偏倚不能消除。没有非糖尿病比较组，因此不能声称关联强于非糖尿病人群或“糖尿病特有机制”。ELSA死亡识别不完整，失访不能当作生存无事件。本研究只提供关联及跨队列复核。
