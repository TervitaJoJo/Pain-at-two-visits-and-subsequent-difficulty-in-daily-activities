# Duration imputation validity correction, 29 October 2026
Manual audit found 13 imputed duration values across 50 HRS imputations (28,550 imputed duration cells) exceeding recipient age + 1 year. Original observed data had already used this calendar-rounding validity bound. Before final reporting, duration predictive mean matching was constrained by rejection-resampling only the invalid draws from the same PMM procedure; measured values remain untouched. No observations were excluded and no exposure, outcome or analytic model was selected on the basis of association estimates. All HRS revision imputation-based analyses were rerun with the same initial seed, 50 imputations and 20 iterations. Other revision outputs were regenerated by the same script. The unbounded interim outputs are archived under superseded_unbounded_duration and must not be used in the manuscript. The original primary analysis is unchanged.
