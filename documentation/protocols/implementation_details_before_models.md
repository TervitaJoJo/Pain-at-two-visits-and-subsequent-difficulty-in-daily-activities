# 正式建模实施细则（关联估计前固定）

日期：2026-10-29。原方案保存在 audit/frozen_analysis_plan_v1.md，哈希见 plan_lock.json。此细则在 HRS 与 ELSA 的任何关联模型运行前写入；没有更换主暴露、结局、对比或调整集。

1. 使用 R mice，各队列、纵向与横断面样本分别插补，50 次、20 轮，固定种子。二元缺失用 logreg；三档教育以无序因子用 polyreg；CES-D8、共同功能项目数用 PMM（5 个供体）。纵向插补辅助信息为观察到的首次事件指示、有效随访区间数及累计已观察区间年数；零区间者的“观察到事件=0”仅编码没有观察到事件，联合零随访信息使用，不向分析填入无事件结局。基线共同功能项目数作为辅助变量，不进入主回归调整集。保存插补对象与链诊断，验证插补不改变已观察值。
2. 主模型使用 binomial(cloglog)，offset=log(实际区间年数)，cluster=参与者，sandwich HC1。多重插补后每个预设线性对比用 Rubin + Barnard–Rubin 自由度合并，完整数据自由度用独立参与者数减模型参数数。完整病例同模型，协变量缺失者整人排除。
3. 主要对比 11 vs 00；三个次要对比额外给出队列内 Holm 校正 P 值，主对比不并入该族。所有原始 P 值和 95%CI 均报告；敏感性分析不按显著性挑选。
4. 观察概率敏感性：所有入组者均进入第一波观察模型；第一波观察到且无事件者进入第二波。固定 pooled logistic 分母为暴露+主协变量+入组窗口+随访区间；分子为暴露+入组窗口+随访区间。逐人累乘分子/分母概率，在已观察区间的 1%/99%分位截尾。每次插补重新拟合权重；报告区间权重及有效样本量。加权 cloglog 使用 quasibinomial 避免非整数二项权重警告，稳健协方差；点估计与同权重 binomial 目标一致。协方差视权重为固定，未完整计入权重估计不确定性，因此仅作敏感性。此权重不代表调查抽样权重。
5. 功能敏感性：基线跨房间行走、椅子起立、上一层楼梯三个共同项目困难数（0–3），要求三个项目均有效，否则由 PMM 插补。主模型加该计数。它用于控制较轻的基线功能差异，不能证明因果作用独立于所有功能状态。
6. 严重度敏感性：仅两组基线有疼痛者（10、11），主协变量加基线 mild/moderate/severe 三档因子，比较 10 vs 11。仅排除严重度未知者；其他协变量沿用多重插补。HRS C105 1/2/3 与 ELSA painlv 1/2/3 对应，文档已核验。不用包含“无痛”的严重度和四组暴露同时回归，避免结构性共线。
7. 死亡敏感性仅 HRS：每个随访波次 ADL=1 或 iwstat 属于已死亡代码3/5/6定义复合事件，观察到 ADL=0 且未报告死亡则为0，否则缺失；遇首次缺失或事件停止。此为按波次的复合结局，统一名义两年区间（offset log2），单独标注；不把死亡月当作 ADL 精确发病日，也不与主模型的实际间隔估计混称。核验得361名随访结束前已死亡者，其中5名死亡月份不全，已知死亡月份均晚于landmark；死亡状态足以定义波次复合事件，无需填造死亡月份。死亡敏感性是诊断稳健性，不能恢复死亡前未报告的ADL。ELSA不做这一分析。
8. 模型诊断额外报告主模型最大预测概率、收敛、设计矩阵秩、稳健协方差、影响和共线性；按预定的两个随访区间加入暴露交互，展示区间特异效应，检查比例效应近似，不用交互结果替代主模型。年龄与CES-D的线性形式另以3自由度自然样条作为诊断敏感性，统一两库实施。
9. 横断面独立样本采用最早有效本人访视；50次插补主模型为稳健Poisson（HC1），无随访区间，无offset；报告当前频繁疼痛 vs 无频繁疼痛的患病率比，以及完整病例结果。其与纵向样本可能重叠，不能称为额外独立验证。
10. 所有分析未加复杂抽样调查权重，目标为符合条件的分析样本中的调整关联，不估计全国总体患病率。无需把样本人数/事件数冒充事先功效分析。
