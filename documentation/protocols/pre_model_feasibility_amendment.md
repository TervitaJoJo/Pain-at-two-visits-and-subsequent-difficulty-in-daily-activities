# Pre-model feasibility amendment

Written after cohort/measurement counts, before fitting any new association model. The original plan and hash remain intact.

1. SHARE's second candidate entry (wave 6, exposure pair 6/7) has almost no observed current-smoking responses because BR002 was restricted by questionnaire routing. Extrapolating imputed current smoking for essentially this entire entry stratum is avoidable. Therefore the primary SHARE replication uses the single wave-5/6 exposure window and wave-7/8 outcomes. Keep the combined-window extraction as an audit artifact, but do not fit or select between its association results. This decision uses measurement availability, not effect estimates or P values. No entry term is needed for the resulting single-window model.
2. In wave 5, BR022 is a follow-up correction to BR002. When BR022=3 (still smoking nowadays), current smoking=1; BR022=1 or 2 implies 0. This correction takes precedence over BR002; it changes no study eligibility rule. Apply it before any models.
3. Official SHARE generic questionnaires confirm the repeated wording is 'Are you troubled with pain?' in both waves. It does not contain HRS/ELSA's word 'often'; report this measurement difference. SHARE's eating item also explicitly includes cutting up food. The cohort is a close conceptual replication, not verbatim-identical measurement.
4. Retain CHARLS 2011/2013 as exploratory replication with different pain recall periods, as specified originally. No cohort is dropped because of significance.
